# Data Analytics Internship Portfolio

This repository contains the projects I worked on during my Data Analytics internship.

The projects cover different stages of data analysis, including data cleaning, exploratory data analysis, SQL analysis, Power BI dashboarding, statistical analysis, and presenting business insights.

## Projects

### 1. Data Cleaning & Wrangling

**Repository:** [Data-Analytics](https://github.com/Lucky5683/Data-Analytics)

This project focuses on cleaning and preparing raw data for further analysis.

**Work included:**
- Data collection and preprocessing
- Handling missing values
- Removing duplicate records
- Feature engineering
- Transforming datasets into an analysis-ready format

**Tools & Skills:** Python, Pandas, Data Cleaning, Data Wrangling

---

### 2. Exploratory Data Analysis & Business Intelligence

**Repository:** [EDA](https://github.com/Lucky5683/EDA)

This project focuses on understanding the data and finding useful patterns and business insights.

**Work included:**
- Descriptive analysis
- Revenue trend analysis
- Product performance analysis
- SQL-based business queries
- Correlation analysis
- Identifying important KPIs

**Tools & Skills:** Python, SQL, EDA, Data Visualization, Business Intelligence

---

### 3. Interactive Dashboarding & Deep-Dive Analysis

**Repository:** [Interactive-Dashboarding-APEX-](https://github.com/Lucky5683/Interactive-Dashboarding-APEX-)

This project focuses on presenting business information through an interactive Power BI dashboard.

**Work included:**
- Defining and tracking KPIs
- Customer segmentation
- Detailed business analysis
- Creating interactive dashboards
- Using filters and slicers
- Identifying and presenting business insights

**Tools & Skills:** Power BI, Dashboarding, KPI Analysis, Customer Segmentation

---

### 4. Data Storytelling & Statistical Validation

**Repository:** [Interactive-Dashboarding-Repository](https://github.com/Lucky5683/Interactive-Dashboarding-Repository)

This project focuses on using statistical analysis to support business findings and presenting the results clearly.

**Work included:**
- Business storytelling
- Hypothesis testing
- T-test analysis
- Interpreting analytical results
- Providing data-driven recommendations
- Preparing presentations for stakeholders

**Tools & Skills:** Statistics, Hypothesis Testing, T-Test, Data Storytelling, Business Communication
